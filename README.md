# HappySmile AI Receptionist

Interactive React + Vite prototype for a dental clinic enquiry-to-appointment workflow.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this repository in Vercel and use the standard Vite preset. The build command is `npm run build` and the output directory is `dist`. No environment variables or backend configuration are required.

The application uses local React state and fictional demo data only.
